Help Build the Boat

Levi could use your computer for a few hours overnight. One setup command, then a simple web page for everything else — no coding, and one command removes it all when you're done.

Please read this whole page before installing anything. It's short, and the end shows how to remove it again. Questions, or stuck anywhere? Text or call Levi at 419-302-6917.

He's building a cardboard canoe for a college engineering class, and the boat's hull shape gets picked by testing thousands of random designs against real physics — hull stability, cardboard strength, paddling speed — rather than guessing. More computers running overnight means more designs get checked before the race.

Your part: about 10 minutes of setup, then leave the computer on and plugged in overnight (or however long you can spare). It uses spare CPU and under 1 GB of RAM, and everything lives in one folder.

01

Turn on Linux-inside-Windows

One time only.

The simulator is built for Linux and Mac terminals, so this turns on WSL — Microsoft's own, contained Linux that lives inside Windows without touching anything else on your PC.

  1. Right-click the Start button and choose Terminal (Admin) — on older Windows it's called Windows PowerShell (Admin). Click Yes on the permission popup.
  2. Paste this and press Enter:
wsl --install -d Ubuntu
  1. When it finishes, restart your computer.
  2. After it restarts, open the new Ubuntu app from the Start menu. The first time, it asks you to make up a username and password — anything works; it's only for this Linux, not your Windows login.
Both times it asks for that password (once to set it, once to confirm), nothing will show on screen as you type — no dots, no cursor moving. That's normal, not frozen. Type it anyway and press Enter.
If it then asks about sending usage data, decline it — backspace to clear whatever's already typed in the box, type n, and press Enter. You won't have this installed long enough for it to matter, and skipping it saves a little time.
02

Paste one command into Ubuntu

Right after step 1. It's the only command you'll ever type.

Paste this into the Ubuntu window (right-click pastes) and press Enter:

cd ~ && { command -v git >/dev/null && python3 -c "import ensurepip" 2>/dev/null || { sudo apt update && sudo apt install -y git python3-venv python3-pip || true; }; } && { [ -d cuBoatRaceSimulation2026 ] || git clone https://github.com/leviholliday/cuBoatRaceSimulation2026.git; } && cd cuBoatRaceSimulation2026 && { git pull -q --ff-only || true; } && python3 -m venv .venv && .venv/bin/pip install --disable-pip-version-check -r requirements.txt && .venv/bin/python scripts/guest_panel.py

Partway through it asks for the Ubuntu password you just made up — type it and press Enter (nothing shows while you type; that's normal). When it's ready, a little boat appears in the window along with the page's address, and your browser opens it. If the browser doesn't open, go to http://localhost:8420.

Leave the Ubuntu window open while the search runs. Minimizing it is fine. On Windows, closing it can shut Linux down and stop the search. Closing the browser is always fine.
01

Paste one command into Terminal

One time only. It's the only command you'll ever type.

Macs already have what this needs. Open Terminal (press Cmd+Space, type "Terminal", press Enter), paste this, and press Enter:

cd ~ && { [ -d cuBoatRaceSimulation2026 ] || git clone https://github.com/leviholliday/cuBoatRaceSimulation2026.git; } && cd cuBoatRaceSimulation2026 && { git pull -q --ff-only || true; } && python3 -m venv .venv && .venv/bin/pip install --disable-pip-version-check -r requirements.txt && .venv/bin/python scripts/guest_panel.py start

When it's ready, a little boat appears in Terminal along with the page's address, and your browser opens it. If the browser doesn't open, go to http://localhost:8420. After that you can close Terminal — the search keeps running on its own.

If a popup asks to install "command line developer tools" — that's normal on a Mac that hasn't used these tools before. Click Install, wait for it to finish, then paste the same command again.
01

Paste one command into a terminal

One time only. It's the only command you'll ever type.

Open a terminal (Ctrl+Alt+T on most desktops, including Raspberry Pi OS — or SSH in), paste this, and press Enter:

cd ~ && { command -v git >/dev/null && python3 -c "import ensurepip" 2>/dev/null || { sudo apt update && sudo apt install -y git python3-venv python3-pip || true; }; } && { [ -d cuBoatRaceSimulation2026 ] || git clone https://github.com/leviholliday/cuBoatRaceSimulation2026.git; } && cd cuBoatRaceSimulation2026 && { git pull -q --ff-only || true; } && python3 -m venv .venv && .venv/bin/pip install --disable-pip-version-check -r requirements.txt && .venv/bin/python scripts/guest_panel.py start

If it asks for your password (only when it needs to install git or Python's venv tools), type it and press Enter — nothing shows while you type. When it's ready, a little boat appears in the terminal along with the page's address, and your browser opens it. After that you can close the terminal — the search keeps running on its own.

No screen on this computer? On a Raspberry Pi you reach over SSH, nothing can pop up there — so the terminal shows a different address instead, like http://192.168.1.23:8420. Open that on your phone or laptop, on the same Wi-Fi.
If the install part complains It only tries to install git and Python's venv tools if they're missing, and a failure there won't stop the rest of the command — some setups (Kali, VMs, rolling-release distros) complain even when the tools are already there. Not on Ubuntu, Debian, Kali or Raspberry Pi OS? Install git and python3 with venv the way your system normally does, then paste the command again.

+

Removing it afterward

Whenever you want your computer back exactly how it was.

Send your results first. Removing it deletes them from this computer.

Open Windows PowerShell (not the Ubuntu window), paste this, and press Enter. It removes the desktop icon and deletes the whole Linux install — the search, the page, and everything in them:

Remove-Item "$([Environment]::GetFolderPath('Desktop'))\Canoe Hull Search.*" -ErrorAction SilentlyContinue; wsl --unregister Ubuntu

That leaves WSL itself turned on, which uses nothing while it's idle. To turn it off too, also run wsl --uninstall.

Paste this into a terminal and press Enter. It asks you to type yes, then stops the search and the page, removes the desktop icon, and deletes the folder:

~/cuBoatRaceSimulation2026/.venv/bin/python ~/cuBoatRaceSimulation2026/scripts/guest_panel.py uninstall
Nothing else on your computer was touched. No background services, no settings changed, nothing left behind.
