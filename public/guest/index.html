Guest Shift

Levi could use your computer for a few hours overnight. A couple of setup steps, then a simple web page for everything else — no coding required, and it leaves nothing behind when you're done.

He's building a cardboard canoe for a college engineering class, and the boat's hull shape gets picked by testing thousands of random designs against real physics — hull stability, cardboard strength, paddling speed — rather than guessing. More computers running overnight means more designs get checked before the race.

Your part: ~10 minutes of setup, then everything else happens in a browser tab — type your name, click a button, leave your PC on and connected overnight (or however long you can spare). It uses spare CPU only — a sliver of RAM, nothing installed outside one folder, and it's gone completely the moment you run the one cleanup command at the end.

NeedsWindows, Mac, or Linux

Reversibleone command, below

01

Turn on Linux-inside-Windows

One time only. No typing — just a download.

The project's tooling is built for Linux/Mac terminals. Rather than hand-translate every command for Windows, this turns on WSL — a real, contained Linux environment that lives inside Windows without affecting anything else on your PC.

⬇ Download guest-setup.bat

Double-click the downloaded file, click Yes on the one Windows permission popup, and let it run — that's the whole step.

  1. When it says "Done," restart your computer.
  2. After it restarts, open the new Ubuntu app from your Start menu — that's the only terminal window you'll need, for one more command in step 2. It'll ask you to make up a username and password on first launch; anything works, it's local to this and unrelated to your Windows login.
What that file actually does It's a plain text script — free to open in Notepad first if you want to see for yourself. It just runs Windows's own wsl --install command for you, so you never have to open an admin terminal by hand.
02

Get the project running

One time only, right after step 1 — then never touch the terminal again.

This is the only command you'll ever type. Paste it into that new Ubuntu window and press enter — it installs a couple of small tools, downloads the code, sets it up, and immediately opens a normal web page where you'll do everything else:

(sudo apt update && sudo apt install -y git python3-venv python3-pip) || true; git clone https://github.com/leviholliday/cuBoatRaceSimulation2026.git && cd cuBoatRaceSimulation2026 && python3 -m venv .venv && .venv/bin/pip install -r requirements.txt && nohup .venv/bin/python scripts/guest_panel.py > panel.log 2>&1 &

It'll ask for the password you just made up for Ubuntu partway through (that's normal for sudo) — type it and press enter, nothing will show on screen as you type, that's expected. A browser tab should then pop open on its own once it's ready (takes under a minute total). If it doesn't, open one yourself and go to http://localhost:8420.

The last piece, nohup ... guest_panel.py &, starts that web page as its own background process, so closing this terminal doesn't stop it or the search.

+

Removing it afterward

Whenever you want your computer back to exactly how it was.

Windows (used WSL)

Run in a normal Windows PowerShell (not inside the Ubuntu window) — this deletes the entire Linux environment and everything inside it in one shot:

wsl --unregister Ubuntu

If you also want WSL itself gone, not just this Linux install: wsl --uninstall. Neither is required — most people just leave WSL on, since it uses no resources while nothing's running in it.

Mac or Linux

Nothing was installed system-wide — just delete the folder:

rm -rf ~/cuBoatRaceSimulation2026
Nothing else on your computer was touched. No registry changes outside WSL's own install (Windows), no background services, nothing that outlives that one command.
